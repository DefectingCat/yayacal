# 今日周期页设计

## 背景

经期首页的状态卡只显示「距下次经期 N 天」和一个周期进度环，看不出当天处在周期的哪个阶段。参考其他经期应用的「今日密报」，新增一个单独页面：左右滑动切换日期，每天一张卡片，用四段圆环和鸭鸭表情展示当天所处的阶段。

只用现有文档和预测结果推算，不改数据模型，也不改后端。

## 范围

- 入口：点击首页状态卡进入，页面标题「今日周期」。
- 日期范围：往前到当前周期之前的第 3 个周期的开始日，往后到下一次预测经期结束日。不做视频里「只能看到明天」的限制。
- 每张卡片：阶段标题（例如「黄体期 · 第 7 天」）、副标题、四段圆环、指针和中间的鸭鸭。
- 点击标题旁的 ⓘ，在底部面板说明四个阶段。
- 没有任何记录时，只有今天一张卡片，提示先记录一次经期。

## 阶段计算 `PeriodPhase.kt`

先把记录和预测串成连续的周期 `CycleSpan`：已记录的每次经期是一个周期的开始，后面接 `PeriodForecast.predictedStarts` 里的预测开始日。每个周期包括：

- `start`：经期开始日。
- `periodEnd`：经期最后一天。已结束的记录取真实结束日；进行中的取 max(开始日 + 经期长度 − 1, 今天)；预测的取开始日 + 经期长度 − 1。
- `nextStart`：下次经期开始日。优先取下一条记录；最后一条记录取预测的第一个开始日，推迟时取原预计开始日；最后一个预测周期取开始日 + 周期长度。
- `ovulation`：`nextStart` − 黄体期天数（设置项，默认 14）。若不晚于 `periodEnd`，说明周期太短，记为没有排卵日。

某一天 D 的阶段：

| 条件 | 阶段 | 第几天 |
| --- | --- | --- |
| D ≤ periodEnd | 月经期 | D − start + 1 |
| periodEnd < D < ovulation | 卵泡期 | D − periodEnd |
| D = ovulation | 排卵日 | 1 |
| D > ovulation，或没有排卵日 | 黄体期 | D − (ovulation ?: periodEnd) |

特殊情况：

- 推迟：已过预计开始日仍没有记录经期，从预计开始日到今天都显示为推迟。预计开始日当天显示「预计经期开始」，之后显示「经期推迟 · 第 N 天」。
- 忘记结束：进行中的经期已经长过预测周期时，丢弃落在经期内的预测开始日。
- 过去的周期用真实的下一次开始日划分，排卵日同样按黄体期天数估算。

已用参考视频核对：10 月 16 日来经期、黄体期 14 天，则 10 月 2 日为排卵日，10 月 9 日为黄体期第 7 天。

## 界面 `PeriodPhaseScreen`

```
┌────────────────────────────────┐
│ ‹  今日周期               回到今天 │  顶部浅粉渐变
│   10/8 周四    今天    10/10 周六  │  日期条，跟随卡片滑动，点击跳转
│ ┌────────────────────────────┐ │
│ │ 黄体期 · 第 7 天  ⓘ           │ │
│ │ 距离下次经期（10月16日）还有 7 天 │ │
│ │          月经期                │ │
│ │     ╭───────────╮             │ │
│ │ 黄体期│  鸭鸭表情  │卵泡期        │ │  当前阶段高亮并按天画小圆点，
│ │     ╰─●─────────╯             │ │  指针从中心指向当天
│ │      ✿ 排卵日                  │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

- `HorizontalPager` 每页一张卡片，左右露出相邻卡片的边缘。日期条按 `currentPage + currentPageOffsetFraction` 平移，离中心越远越淡。
- 未来日期在标题旁标「预测」。
- 圆环在 `Canvas` 中绘制：从 12 点钟方向顺时针，每天占 360° / 周期长度。依次是月经期、卵泡期、排卵日（小花图标）、黄体期。当前阶段使用实色和每天的小圆点，其他阶段使用淡色。阶段长度因人而异，所以圆环不用图片。
- 圆环中心的鸭鸭按状态取图：月经期、卵泡期、排卵日、黄体期、推迟、无记录各一张。
- 颜色：`PeriodPalette` 新增卵泡期绿色、黄体期橙色，与已有的经期玫红、排卵日紫色一起，亮色和暗色各一套。

## 素材

由 AI 生成的 3 × 2 表情合集切成 6 张 512px WebP，另有一张 256px 的排卵日小花，都放在 `core/src/main/res/drawable-nodpi/`：

- `period_duck_menstrual`、`period_duck_follicular`、`period_duck_ovulation`、`period_duck_luteal`、`period_duck_late`、`period_duck_empty`
- `period_ovulation_flower`

## 文件清单

- `PeriodPredictor.kt`：`PeriodForecast` 增加 `predictedStarts`。
- `PeriodPhase.kt`：`CyclePhase`、`CycleSpan`、`PeriodDayInfo`、`PeriodTimeline`。
- `ui/PeriodPhaseScreen.kt`：页面、日期条、卡片、阶段说明面板。
- `ui/PeriodPhaseRing.kt`：圆环、指针和鸭鸭。
- `ui/PeriodComponents.kt`：新增阶段配色。
- `ui/PeriodTrackerScreen.kt`：状态卡可点击。
- `:app`：`PeriodPhaseActivity`，在 manifest 注册；`PeriodTrackerActivity` 增加跳转。
